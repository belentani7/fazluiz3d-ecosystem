Gemini CLI Screenshot

Gemini CLI is an open-source AI agent that brings the power of Gemini directly into your terminal. It provides lightweight access to Gemini, giving you the most direct path from your prompt to our model.

Learn all about Gemini CLI in our documentation.

🚀 Why Gemini CLI?
🎯 Free tier: 60 requests/min and 1,000 requests/day with personal Google account.
🧠 Powerful Gemini 3 models: Access to improved reasoning and 1M token context window.
🔧 Built-in tools: Google Search grounding, file operations, shell commands, web fetching.
🔌 Extensible: MCP (Model Context Protocol) support for custom integrations.
💻 Terminal-first: Designed for developers who live in the command line.
🛡️ Open source: Apache 2.0 licensed.
📦 Installation
See Gemini CLI installation, execution, and releases for recommended system specifications and a detailed installation guide.

Quick Install
Run instantly with npx
# Using npx (no installation required)
npx @google/gemini-cli
Install globally with npm
npm install -g @google/gemini-cli
Install globally with Homebrew (macOS/Linux)
brew install gemini-cli
Install globally with MacPorts (macOS)
sudo port install gemini-cli
Install with Anaconda (for restricted environments)
# Create and activate a new environment
conda create -y -n gemini_env -c conda-forge nodejs
conda activate gemini_env

# Install Gemini CLI globally via npm (inside the environment)
npm install -g @google/gemini-cli
Release Channels
See Releases for more details.

Preview
New preview releases will be published each week at UTC 23:59 on Tuesdays. These releases will not have been fully vetted and may contain regressions or other outstanding issues. Please help us test and install with preview tag.

npm install -g @google/gemini-cli@preview
Stable
New stable releases will be published each week at UTC 20:00 on Tuesdays, this will be the full promotion of last week's preview release + any bug fixes and validations. Use latest tag.
npm install -g @google/gemini-cli@latest
Nightly
New releases will be published each day at UTC 00:00. This will be all changes from the main branch as represented at time of release. It should be assumed there are pending validations and issues. Use nightly tag.
npm install -g @google/gemini-cli@nightly

Basic Usage
Start in current directory

Include multiple directories
gemini --include-directories ../lib,../docs
Use specific model

Non-interactive mode for scripts
Get a simple text response:

gemini -p "Explain the architecture of this codebase"
For more advanced scripting, including how to parse JSON and handle errors, use the --output-format json flag to get structured output:

gemini -p "Explain the architecture of this codebase" --output-format json

gemini -p "Run tests and deploy" --output-format stream-json

## [ASSISTANT] 2026-07-14 06:13 · Qwen3.7-Plus

Siendo **bien realista y sin el filtro del marketing**, aquí tienes un análisis objetivo de las fortalezas y debilidades de Google AI (Gemini) frente a los mayores modelos del mundo (como GPT-4o de OpenAI o Claude 3.5 Sonnet/Opus de Anthropic), junto con una evaluación honesta del plan de suscripción que has compartido y cómo encaja con tu perfil.

---

### 1. Google AI (Gemini) vs. la Competencia: La Realidad sin Filtros

#### **Fortalezas reales (Donde Google aplasta a la competencia)**
1. **Ventana de contexto masiva y nativa:** Los modelos Gemini (especialmente las versiones Pro y las nuevas iteraciones mencionadas en el CLI con 1 millón+ de tokens) son superiores procesando volúmenes brutos de datos. Puedes subir un repositorio de código entero, un libro de 500 páginas o horas de video, y el modelo lo "recordará" y relacionará sin perderse. OpenAI y Anthropic aún luchan con la "pérdida en el medio" (lost in the middle) en contextos tan grandes.
2. **Multimodalidad de origen:** A diferencia de otros modelos a los que se les "añadió" visión después, Gemini se entrenó desde cero con texto, audio, imagen y video juntos. Esto se traduce en una comprensión más fluida de videos largos o flujos de audio en tiempo real.
3. **Velocidad y coste (Gemini Flash):** Para tareas de alto volumen, resumen de documentos o análisis de datos, la versión Flash ofrece una relación velocidad/precio imbatible en el mercado.
4. **Herramientas para desarrolladores (Gemini CLI):** Como se ve en el texto que compartiste, Google está ofreciendo **1.000 peticiones/día gratis** con cuenta personal, soporte para MCP (Model Context Protocol) y ejecución en terminal. Es una jugada estratégica brutal para captar a desarrolladores que antes dependían de herramientas de pago.

#### **Debilidades honestas (Donde la competencia aún gana)**
1. **Razonamiento lógico puro y código complejo:** En benchmarks de matemáticas avanzadas, lógica de múltiples pasos o generación de código muy matizado, **Claude 3.5 Sonnet** y los modelos **o1 de OpenAI** suelen ser más rigurosos, cometen menos "alucinaciones" y ofrecen soluciones más elegantes.
2. **Fluidez y "personalidad":** Muchos usuarios y profesionales perciben las respuestas de Gemini como más robóticas, genéricas o con un tono excesivamente "de asistente corporativo" en comparación con la redacción natural y matizada de Claude.
3. **Dependencia del ecosistema:** Si no vives dentro de Google (Android, Gmail, Drive, Workspace), el valor de sus herramientas se desploma.

---

### 2. Evaluación Realista del Plan "Google AI Plus / Pro"

Basado en los datos que has pegado, este no es solo un plan de almacenamiento, es un intento de Google de crear un "súper paquete" de productividad.

- **La matemática real (El verdadero truco):** El plan permite **compartir con hasta 5 personas**. 
  - El plan de **2 TB a 99,99 €/año** dividido entre 6 personas sale a **~16,60 € al año por persona** (menos de 1,40 €/mes). 
  - Por ese precio, cada persona obtiene: 333 GB de almacenamiento, acceso a modelos Gemini avanzados, YouTube Premium Lite y funciones extra de Meet/Calendar. **Es una de las mejores relaciones calidad-precio del mercado**, muy por debajo de lo que cuesta Microsoft 365 Family o Copilot Pro por separado.
- **YouTube Premium Lite:** Ojo con la letra pequeña. "Lite" generalmente significa solo **sin anuncios**. Es probable que *no* incluya descargas offline ni YouTube Music. Aun así, para consumo diario en casa, es un valor añadido enorme.
- **Google Health y Home Premium:** Son útiles *solo si* ya tienes un Pixel Watch, Fitbit o dispositivos Google Home. Si no, es ruido de marketing.

---
