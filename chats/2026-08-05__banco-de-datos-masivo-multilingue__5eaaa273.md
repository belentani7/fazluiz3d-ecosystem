# El Ecosistema Digital Abierto: Un Mapa de Fuentes Masivas para Recursos Educativos en Portugués y 38 Idiomas

## Repositorios Globales de Libros y Textos Educativos Abiertos

La disponibilidad de libros y textos educativos en formato digital abierto constituye uno de los pilares fundamentales para la democratización del conocimiento. La investigación revela un robusto ecosistema de repositorios globales que, en conjunto, forman un banco de datos masivo y escalable. Estos repositorios no solo proporcionan acceso gratuito a millones de títulos, sino que también sirven como agregadores de colecciones nacionales y bibliotecas institucionales, creando un tejido interconectado de recursos culturales y académicos. La naturaleza de estos recursos varía desde obras completamente en dominio público hasta aquellos distribuidos bajo licencias Creative Commons que permiten su uso, modificación y redistribución [[2,39]]. La comprensión de la arquitectura de estos repositorios es crucial para diseñar herramientas de búsqueda y acceso eficientes.

El pilar de este ecosistema es Internet Archive, cuya biblioteca de texto contiene más de 624 mil millones de páginas web archivadas y miles de millones de documentos digitales [[175,497]]. Su Open Library es un proyecto ambicioso que aspira a crear un registro digital para cada libro jamás publicado, habiendo ya digitalizado 35 millones de volúmenes . Este repositorio es invaluable por su amplitud y por albergar colecciones históricas y especializadas, como la NASA Image and Video Library, donde todo el contenido está en dominio público y es ideal para la educación en ciencias y tecnología . De manera similar, HathiTrust Digital Library alberga 17 millones de volúmenes digitalizados, ofreciendo acceso completo a lo que está en dominio público y búsqueda textual a lo protegido por derechos de autor [[6]]. Otro actor global de primer orden es Europeana, que agrega más de 60 millones de objetos digitales de bibliotecas, archivos y museos de toda Europa, incluyendo una vasta cantidad de textos en todos los idiomas europeos y latinoamericanos [[53]].

En el ámbito de los idiomas específicos, Project Gutenberg sigue siendo una referencia histórica, con más de 70,000 libros disponibles en formatos electrónicos listos para usar, destacando por su fuerte representación en inglés, francés, alemán, chino y portugués . Para una mayor calidad pedagógica, Standard Ebooks ofrece ediciones modernas, maquetadas y corregidas de clásicos de Project Gutenberg, mejorando significativamente la experiencia de lectura para estudiantes y educadores . En el contexto hispanohablante, la Biblioteca Digital Hispánica de España y la Biblioteca Virtual Miguel de Cervantes son ejemplos de repositorios nacionales de gran relevancia . Finalmente, iniciativas como Wikisource proporcionan una plataforma multilingüe para la colaboración colectiva en la creación y curación de textos libres .

Para el ámbito de los recursos educativos abiertos (OER), la oferta es igualmente diversa y masiva. OER Commons y MERLOT son plataformas globales que agrupan miles de recursos educativos, incluyendo libros de texto, módulos de aprendizaje y materiales de evaluación, todos etiquetados con sus respectivas licencias de uso [[64,267,273]]. Plataformas como OpenStax y Open Textbook Library se centran en la provisión de libros de texto universitarios revisados por pares, principalmente en inglés y español, aunque OpenStax ha comenzado a establecer enlaces hacia traducciones comunitarias para ampliar su alcance lingüístico [[61]]. En el ámbito científico y técnico, repositorios como arXiv, PubMed Central y CORE indexan artículos de investigación en dominio público o bajo licencias abiertas, funcionando como bases de datos masivas para la comunidad académica [[3]]. La clave de esta infraestructura es que muchos de estos repositorios permiten búsquedas avanzadas filtrables por idioma, lo cual es fundamental para cumplir con el objetivo de acceder a contenido en 39 idiomas [[640]].

Este análisis demuestra que, si bien no existe un único "banco de datos" centralizado, sí existe un ecosistema de repositorios masivos que, cuando se combinan, satisfacen plenamente el requisito de volumen y accesibilidad. La estrategia más efectiva para el usuario consistirá en desarrollar una herramienta que pueda consultar estos repositorios de manera integrada, aprovechando las capacidades de búsqueda avanzada que ofrecen cada uno de ellos, especialmente el filtrado por idioma y licencia.

## Agregadores Audiovisuales y Plataformas de Educación Superior Gratuitas

El acceso a material audiovisual educativo representa un componente vital de la investigación, abarcando desde documentales y películas hasta conferencias y cursos completos. Al igual que con los libros, la solución no reside en un único repositorio, sino en un ecosistema de plataformas y agregadores que ofrecen volumen masivo de contenido legal y gratuito. Estas fuentes se pueden clasificar en tres categorías principales: bibliotecas de archivo masivas, plataformas de video con licencias abiertas y servicios de educación superior que permiten el acceso gratuito en modo de auditoría. La distinción entre contenido verdaderamente libre (dominio público, Creative Commons) y contenido gratuito con soporte publicitario (como los canales FAST) es fundamental para cumplir con los criterios del usuario .

El recurso más grande y diversificado en este ámbito es, sin duda, la sección de video de Internet Archive . Esta biblioteca digital contiene millones de videos, incluyendo películas pre-1929 (dominio público en EE.UU.), documentales educativos, noticieros históricos, conferencias y programas infantiles [[498]]. Su fortaleza radica en la preservación de material histórico valioso que podría estar perdido de otro modo [[499]]. Wikimedia Commons complementa esta oferta con una base de datos masiva de archivos multimedia libres, lo que lo convierte en una excelente fuente para clips educativos cortos, ejemplos de pronunciación y material cultural específico por país o región . Para la educación en ciencias espaciales, la NASA Image and Video Library es un recurso indispensable, ya que todo su contenido es dominio público y cuenta con subtítulos en múltiples idiomas .

TED Talks ofrece una plataforma masiva de charlas educativas de expertos en diversos campos . Aunque la mayoría de las presentaciones están bajo una licencia Creative Commons Attribution-Non-Commercial-No Derivatives 4.0 International (CC BY-NC-ND), una parte significativa del contenido puede ser filtrada para encontrar aquellas con licencias más permisivas, como la licencia Attribution (CC BY), que permite el uso comercial [[65,176]]. La plataforma proporciona subtítulos oficiales y transcripciones en más de 100 idiomas, lo que la convierte en una herramienta excepcional para el aprendizaje de idiomas y la investigación multidisciplinar .

En el sector de la educación superior, plataformas como Khan Academy, Coursera, edX y MIT OpenCourseWare han revolucionado el acceso al conocimiento universitario. Si bien la obtención de certificados suele requerir pago o inscripción, todas estas plataformas ofrecen el acceso gratuito a sus cursos completos, incluyendo videos, lecturas y exámenes, en un modo de "auditoría" . Khan Academy es particularmente relevante por tener una versión completa y adaptada en portugués, cubriendo desde matemáticas hasta ciencias y humanidades con vídeos, ejercicios interactivos y guías de estudio . Para el contenido documental, CurtaDoc es un recurso brasileño exclusivo que ofrece docuseries completas y gratuitas organizadas por temas educativos como historia, medio ambiente y cultura . Finalmente, los canales de televisión públicos de varios países, como TV Cultura en Brasil y RTP Play en Portugal, ofrecen vastas bibliotecas de programación educativa disponible en demanda de forma gratuita, cubriendo tanto a niños como a adultos [[84]].

El desarrollo de una herramienta de búsqueda debe ser capaz de identificar y mostrar claramente la licencia de cada recurso, diferenciando entre uso personal, académico y comercial. Por ejemplo, el modelo CC BY-NC prohibe el uso comercial, mientras que CC0 (Dominio Público) no impone ninguna restricción [[363]]. La API de Creative Commons puede ser utilizada para generar código HTML que verifique la pertenencia a dominio público, facilitando la integración técnica [[7]]. Esta distinción es primordial para garantizar que el usuario final utilice el contenido dentro de los límites legales establecidos por los creadores.

## Ecosistemas de Música Libre y Archivos de Radio Online

El mundo de la música y los archivos de audio presenta un paradigma diferente al de los libros y videos. Si bien el dominio público es una fuente importante, el ecosistema de música libre se rige predominantemente por las licencias Creative Commons, que otorgan permisos específicos para el uso, la distribución y la modificación de obras protegidas por derechos de autor [[194,269]]. Esto crea un entorno vibrante pero complejo, donde el concepto de "libre" implica un conjunto de condiciones definidas por el autor. La investigación ha identificado varias plataformas masivas que son fundamentales para la educación musical, el aprendizaje de idiomas y la investigación fonográfica.

Jamendo se destaca como un mercado líder para músicos independientes que publican su trabajo bajo licencias Creative Commons [[196,200]]. Con una base de datos que supera las 500,000 pistas de más de 40,000 artistas de todo el mundo, Jamendo opera como una plataforma de distribución que permite a los usuarios encontrar música con licencias explícitas, desde las más permisivas (CC0, atribución) hasta las más restrictivas (atribución-no comercial-sin derivados) [[413,616]]. El sitio proporciona APIs que permiten a los desarrolladores buscar y acceder a esta música, facilitando su integración en proyectos educativos o creativos [[594,615]]. Free Music Archive (FMA) y ccMixter son otras plataformas similares que ofrecen catálogos masivos de música libre, a menudo organizados por género y tipo de licencia, siendo FMA una opción popular para el uso educativo y creativo [[504]].

Para la música clásica, Musopen es una fuente invaluables. Este proyecto se dedica a grabar y publicar partituras, grabaciones y libros de música clásica sin copyright, eliminando barreras legales para la educación musical . Al combinar partituras en dominio público con grabaciones de alta calidad, Musopen proporciona un recurso integral para estudiantes, profesores y aficionados a la música clásica. De manera complementaria, el proyecto SoundSafari/CC0-1.0-Music busca crear la mayor colección posible de música bajo la licencia CC0 (dedicada al dominio público), actualmente conteniendo más de 7,000 canciones y ocupando aproximadamente 40 GB de espacio [[189,191]].

En el ámbito del aprendizaje de idiomas y la comprensión auditiva, LibriVox es una iniciativa masiva y voluntaria que produce audiolibros de obras literarias en dominio público . Con lectores de todo el mundo, LibriVox ofrece una cobertura notable en más de 30 idiomas, incluyendo portugués, lo que lo convierte en un recurso clave para practicar la escucha activa y mejorar la pronunciación . Además de las obras literarias, Internet Archive aloja numerosas colecciones de audio dedicadas al aprendizaje de idiomas, como "Listen & Learn Portuguese" de Alexander R. Prista o "Portuguese for dummies", que incluyen discos de pronunciación grabados por hablantes nativos [[591,618,619,621]].

Finalmente, los archivos de radio online y los agregadores de emisoras en vivo ofrecen acceso a contenido cultural y periodístico auténtico en tiempo real. Radio Garden es una herramienta visualmente atractiva que permite a los usuarios explorar y sintonizar emisoras de radio de todo el mundo con un simple clic, ofreciendo una ventana a las voces locales y las conversaciones actuales en cualquier idioma [[105]]. Para el contexto lusófono, existen guías completas que listan las mejores emisoras de radio de Portugal y Brasil, permitiendo la escucha en línea de contenido local [[105]]. Arquivo.pt, un archivo web portugués, también preserva un valioso patrimonio de contenidos audiovisuales históricos, incluyendo programas de radio que ya no están disponibles en otras partes .

La implementación técnica de un buscador que integre estos recursos debe ser capaz de manejar la complejidad de las licencias. Por ejemplo, al buscar música para un proyecto comercial, el sistema debería priorizar resultados con licencias CC0 o CC BY. Para proyectos académicos, las licencias CC BY-NC podrían ser aceptables. Las APIs de plataformas como Jamendo, que permiten filtrar por tipo de licencia, son esenciales para construir esta funcionalidad [[611,612]]. La correcta gestión de metadatos, incluyendo el idioma original de la letra o el contenido, es igualmente crucial para la relevancia del resultado.

## Canales de Televisión en Vivo Legales y Plataformas de Transmisión Gratuita

La solicitud de contenido de televisión en vivo presenta un desafío particular, ya que la concepción de "televisión en vivo de código abierto" pura es casi inexistente . Sin embargo, la investigación ha revelado un panorama rico y diverso de opciones legales y gratuitas que cumplen con el espíritu de la solicitud. Estas soluciones se dividen en dos grandes categorías: canales públicos y gubernamentales que transmiten contenido de servicio público, y plataformas de streaming gratuito con soporte publicitario (FAST, por sus siglas en inglés), que operan bajo un modelo de negocio basado en anuncios en lugar de suscripciones [[137,140]]. Una herramienta de búsqueda eficaz debe presentar ambos tipos de fuentes de manera clara y distinguirlas adecuadamente.

Los canales de televisión públicos de naciones como Brasil, Portugal y España son una fuente masiva y de alta calidad de contenido educativo y cultural gratuito. En Brasil, TV Cultura es un canal público con una vasta biblioteca de programación educativa infantil y para adultos, disponible en demanda sin costo alguno [[429]]. Del mismo modo, en Portugal, RTP (Radiotelevisão de Portugal), el organismo de radiodifusión pública, opera cuatro canales de televisión nacionales y ofrece su contenido a través de RTP Play, su servicio de transmisión por internet [[84,103]]. RTP Play es un recurso invaluable que incluye noticias, documentales, series y películas en portugués europeo, además de RTP Internacional y RTP África, que difunden contenido lusófono a nivel mundial [[27,318,320]]. Estas plataformas son la alternativa legal directa a la televisión comercial educativa y garantizan la preservación de la producción nacional.

Además de los canales nacionales, existen iniciativas regionales y temáticas. Canal Once de México y TV UNAM de México son ejemplos de canales universitarios que producen y transmiten contenido educativo de vanguardia . En el ámbito internacional, canales como DW (Alemania), France.tv (Francia) y BBC iPlayer (Reino Unido) ofrecen secciones educativas masivas y gratuitas, aunque el acceso a la transmisión en vivo puede variar geográficamente . UNESCO Web TV y la Eurovision News Exchange de la Unión Europea de Radiodifusión (EBU) proporcionan acceso a eventos globales, reuniones y noticias internacionales, a menudo con interpretación simultánea en múltiples idiomas, incluido el portugués [[51,229,230]].

La segunda categoría, los servicios de transmisión de televisión gratuita con soporte publicitario (FAST), representa el crecimiento más rápido en el sector del streaming. Estos servicios, como Pluto TV, Samsung TV Plus, Tubi y The Roku Channel, ofrecen canales lineales gratuitos que no requieren registro ni pago [[37,141]]. Son una fuente masiva de contenido que incluye canales de noticias, documentales, entretenimiento general y, cada vez más, canales educativos y de nicho [[278]]. Muchas de estas plataformas tienen canales en español, inglés y portugués, lo que los convierte en una opción viable para el requisito de multilingüismo [[32,282]]. El principal desafío técnico para integrar estos servicios es la falta de una API universal. La solución más práctica es vincular directamente a los canales relevantes dentro de estas plataformas o utilizar reproductores incrustados donde estén disponibles [[144]].

La transmisión en vivo también se encuentra en plataformas de video generadas por los propios usuarios, como YouTube Live y Twitch. Muchas universidades, organizaciones y expertos transmiten conferencias, clases y eventos en vivo de forma abierta a través de estas plataformas, creando una fuente dinámica y en tiempo real de conocimiento especializado .

Para la integración técnica en un directorio web, la estrategia más segura y eficaz sería una combinación híbrida:
1.  **Incrustaciones (`<iframe>`) directas:** Utilizar los reproductores incrustados oficiales proporcionados por los canales públicos (RTP Play, TV Cultura) siempre que estén disponibles.
2.  **Enlaces directos a FAST:** Proporcionar enlaces a los perfiles o canales específicos dentro de las plataformas FAST como Pluto TV o Samsung TV Plus.
3.  **Agenda de eventos:** Para transmisiones especiales (como el Festival de la Canción de Eurovisión), vincular a las páginas de transmisión oficial de la organización [[437,439]].

Esta aproximación garantiza el acceso legal y gratuito al contenido, evita la violación de políticas de derechos de autor asociadas a flujos piratas y ofrece al usuario la experiencia más directa posible.

## Bases de Datos de Revistas Académicas y Publicaciones Periódicas de Acceso Abierto

El acceso a la literatura científica y académica es un pilar del progreso intelectual, y el movimiento de Acceso Abierto (OA) ha transformado drásticamente este panorama. La investigación ha confirmado la existencia de bases de datos masivas y altamente especializadas que indexan y proporcionan acceso gratuito a un volumen ingente de revistas académicas, periódicos y tesis. Estas plataformas no solo eliminan las barreras económicas del acceso a la información, sino que también promueven la visibilidad y el impacto de la investigación, especialmente en regiones y para idiomas que históricamente han sido subrepresentados.

La piedra angular de este ecosistema es el Directory of Open Access Journals (DOAJ), un directorio curado que indexa más de 20,000 revistas académicas de alto standar que cumplen con los criterios de calidad y transparencia del OA [[424]]. Lo más notable de DOAJ es su compromiso con la diversidad lingüística, ya que indexa revistas en más de 80 idiomas, incluyendo variaciones dialectorales, lenguas indígenas y otras lenguas menos extendidas [[120]]. Esto lo convierte en una herramienta indispensable para cumplir con el requisito de accesibilidad en 39 idiomas. La estrategia de DOAJ es ser el índice más completo y confiable de revistas de acceso abierto de calidad en todo el mundo [[424]].

En el contexto iberoamericano y lusófono, SciELO (Scientific Electronic Library Online) y Redalyc (Red de Revistas Científicas de América Latina y el Caribe, México y Portugal) son gigantes en el campo de las ciencias sociales, humanidades y ciencias exactas e ingeniería . SciELO, concebido en Brasil en 1997, es un modelo de publicación de acceso abierto que gestiona una vasta red de revistas científicas y educativas, con interfaces multilingües pero con contenido primariamente en portugués e español [[130,132]]. Redalyc, por su parte, incluye más de 620 revistas académicas, todas ellas disponibles en texto completo, y su interfaz está disponible en español, portugués, inglés y francés [[290]]. Ambas bases de datos son cruciales para acceder a la producción científica de Iberoamérica y Portugal.

Más allá de estas plataformas regionales, existen agregadores de agregadores que ofrecen una visión aún más amplia. BASE (Bielefeld Academic Search Engine), operado por la Universidad de Bielefeld, es uno de los motores de búsqueda más voluminosos del mundo para recursos académicos de acceso abierto, indexando más de 240 millones de documentos de más de 8,000 fuentes, incluyendo repositorios institucionales, bases de datos de tesis y revistas [[480,481,573]]. Otra herramienta poderosa es CORE (Connecting Repositories), que recopila documentos de miles de repositorios institucionales y de revistas de acceso abierto a nivel mundial [[3,257]]. Estas plataformas de búsqueda masiva son ideales para encontrar literatura específica incluso si no se conoce previamente la revista exacta en la que fue publicada.

Finalmente, las bibliotecas digitales nacionales y de organismos internacionales también juegan un papel crucial. La Biblioteca Digital Mundial de la UNESCO hace accesible a nivel multilingüe tesouros culturales y documentales de bibliotecas de todo el mundo [[53,205]]. El portal de publicaciones de la UNESCO también indexa y proporciona acceso abierto a todos sus documentos y estudios [[421]]. De manera similar, repositorios institucionales como el Harvard Library Public Domain Corpus buscan proporcionar acceso a grandes conjuntos de datos de libros en dominio público para fines de investigación y desarrollo [[119]].

La capacidad de filtrar los resultados no solo por palabra clave, sino también por idioma, tipo de documento (artículo, tesis, capítulo de libro) y, crucialmente, por licencia de acceso, es fundamental para la usabilidad de la herramienta. La distinción entre "Acceso Abierto" y "Gratuito con publicidad" es menos crítica aquí, ya que el término "Acceso Abierto" implica inherentemente que el contenido es libre de acceso y, en la mayoría de los casos, con permisos para uso y reutilización claros, a menudo bajo licencias Creative Commons [[268,271]].

## Análisis Específico del Eje Lusófono y Estrategias de Integración Multilingüe

El requisito prioritario del usuario de enfocarse en el portugués y sus variantes (brasileña, europea y de los países africanos lusófonos) no solo es factible, sino que revela un ecosistema digital vibrante y robusto, impulsado en gran medida por la cooperación internacional a través de la Comunidad de Países de Lengua Portuguesa (CPLP) [[12,18]]. La CPLP, fundada en 1996 por siete países y ahora con nueve miembros, incluye a Portugal, Brasil, Angola, Cabo Verde, Guinea-Bissau, Mozambique, São Tomé y Príncipe y Equatorial Guinea [[12,13,148]]. Esta alianza política y cultural ha generado iniciativas concretas para promover el contenido audiovisual y educativo lusófono, como el Programa Audiovisual de la CPLP (PAV), un esfuerzo conjunto para seleccionar, promover y difundir proyectos de cine y televisión de lengua portuguesa [[167,168,169]].

La viabilidad del eje lusófono se apoya en una base de datos masiva y de alta calidad. En Brasil, el Portal do Domínio Público Brasileiro es un recurso monumental, ofreciendo más de 200,000 obras literarias, artísticas e científicas en dominio público, incluyendo las obras completas de figuras cumbre como Machado de Assis . Proyectos como Projeto Livro Livre se enfocan en la creación de libros de texto abiertos para el sistema educativo brasileño . En Portugal, el RCAAP (Repositório Científico de Acesso Aberto de Portugal) funciona como un repositorio nacional que agrupa tesis, artículos y material educativo de todas las universidades portuguesas, asegurando el acceso abierto a la producción científica nacional . La Biblioteca Nacional Digital de Portugal y el Arquivo.pt (archivo web portugués) completan el panorama, preservando el patrimonio cultural y audiovisual del país .

Para los países africanos lusófonos (PALOP), aunque los recursos individuales pueden ser menores que los de Brasil o Portugal, existen bases de datos y portales especializados que son vitales. El portal TPA OFICIAL es la televisión pública de Angola, ofreciendo contenido local en línea [[369]]. Research Guides como los de Lusophone Africa proporcionan acceso a publicaciones y bases de datos centradas en Mozambique, Angola, Cabo Verde y Guinea-Bissau [[129,473]]. El portal BUALA, aunque más centrado en el cine postcolonial, alberga un archivo de miles de artículos en portugués, francés e inglés sobre el mundo lusófono [[150]]. La distinción entre las variantes lingüísticas es fundamental: el sistema de codificación de idiomas ISO 639-2 distingue claramente entre pt-BR (Português (Brazil)), pt-PT (Portugês (Portugal)) y códigos para las variedades africanas como pt-AO (Angola) y pt-CV (Cabo Verde) [[85,353]]. Una herramienta de búsqueda eficaz debe ser capaz de reconocer y utilizar estos códigos para ofrecer resultados precisos.

Sin embargo, el desafío principal para alcanzar el objetivo de 39 idiomas no reside en la ausencia de contenido, sino en la desigualdad lingüística inherente al ecosistema digital abierto. Según diversas fuentes, alrededor del 80% del contenido de acceso abierto está concentrado en cinco idiomas: inglés, español, francés, alemán y chino [[10]]. Lograr una cobertura equilibrada en 39 idiomas, especialmente los menos hablados, requerirá una estrategia de "agregación inteligente". Esto implica combinar grandes repositorios globales como Internet Archive y BASE con portales regionales y nacionales que puedan llenar los vacíos lingüísticos. Por ejemplo, Global Storybooks ofrece cuentos en más de 40 idiomas, incluyendo lenguas indígenas y africanas, y utiliza la licencia Creative Commons Attribution (CC BY), lo que la convierte en un recurso masivo y flexible para la alfabetización multilingüe .

Las implicaciones técnicas para la integración de estos recursos son profundas. Para que un buscador sea verdaderamente multilingüe y efectivo, debe ir más allá de una simple coincidencia de palabras. La implementación de una arquitectura de metadatos avanzada es imperativa. Esto incluye el uso de etiquetas `lang` en HTML para identificar el idioma del contenido y la consulta de metadatos estructurados como Dublin Core, que permite especificar el idioma de una obra de manera formal [[252]]. Una estrategia poderosa sería la búsqueda bilíngüe automática, donde una consulta en portugués (pt) se traduzca implícitamente o se envíe simultáneamente a las bases de datos en inglés (en), maximizando así la probabilidad de encontrar resultados relevantes incluso si los metadatos existen solo en uno de los dos idiomas .

## 6. Experiencia para Persona 40+ (Lo que la Hace Única)

### 6.1 Onboarding sin Lectura (Nivel 0)
- Primer arranque: 3 pantallas de iconos grandes que se pueden escuchar ("toca para escuchar qué es esto")
- Opción "Me ayudan con esto": muestra pantalla de "pide a un familiar que haga esto contigo" con botón de compartir por WhatsApp
- El test de nivel (5 preguntas) se responde por **voz o por toque de imágenes**, no escribiendo
- Código de cuenta: se crea con 6 símbolos simples (no letras confusas 1/l/I). Se puede guardar como imagen o enviar a un contacto

### 6.2 Navegación de 3 Caminos
En lugar de un menú de 12 secciones: tres botones enormes:
1. **"Estoy llegando"** (primeros pasos, papeles, acogida)
2. **"Necesito trabajo"** (empleo, formación, currículum)
3. **"Me han escrito"** (cartas oficiales, citas, avisos)

Todo lo demás queda en un segundo nivel claramente accesible, pero nunca compite con los 3 caminos.

### 6.3 Cada Trámite es un "Paso a Paso"
- Un trámite = una lista numerada de ≤5 pasos, cada uno con: qué necesitas, dónde vas, qué dices, botón "escuchar", pictograma
- Al final: "¿Lo conseguiste?" (sí/no). El "no" abre un camino de ayuda humana (dónde acudir en tu ciudad)
- Toda pantalla tiene "atrás" y el progreso se guarda instantáneamente

### 6.4 Modo "Solo lo Esencial"
- Interruptor global que reduce la interfaz al mínimo: 3 botones, fuente grande, sin adornos, sin notificaciones, sin animaciones
- Para cuando el usuario está estresado o el contexto es de emergencia

### 6.5 Idioma que se Adapta, no se Impone
- El usuario elige su idioma al empezar (banderas + nombre del idioma en su propia lengua, NO traducido a español)
- Cambiar idioma en 1 toque desde cualquier pantalla (nunca en un submenú)
- Los 5 idiomas principales (es/pt/en/fr/ar) con calidad humana; el resto con traducción automática **marcada** ("traducción automática — puede tener errores")

## 7. Arquitectura de Datos (Esquema Único Compartido)

```typescript
// src/data/schema.ts - UN SOLO ESQUEMA PARA TODOS LOS MÓDULOS

type PlatformUser = {

type Objective = {

type Course = {

  description: string; language: string; source?: string;

  syllabus?: WeeklySyllabus[];
};

type Lesson = {
  id: string; title: string; content: string;
  audio?: boolean; slides?: string[]; quiz?: Question[];
  estimatedTime?: number; // minutos
};

type Question = {
  id: string; text: string; options: string[];
  correctAnswer: number; explanation: string;
};

type MediaItem = {
  id: string; title: string; url: string; channel: string;
  duration?: string; language: string; level: number;
  category: string; verified: boolean; license: string;
  source: 'khan' | 'ted' | 'archive' | 'nasa' | 'librivox' | 'radio-garden' | ...;
};

type InstructorProfile = {
  name: string; bio: string; credentials: string[];
  avatar?: string; social?: Record<string, string>;
};

type WeeklySyllabus = {
  week: number; topic: string; objectives: string[];

  assessments?: string[]; // IDs de quizzes
};

type Certificate = {
  id: string; userId: string; courseId: string;
  issuedAt: string; qrCode: string; shareUrl: string;
};

type ForumPost = {
  id: string; courseId: string; userId: string;
  title: string; content: string; createdAt: string;
  replies: ForumReply[]; votes: number;
};

type ForumReply = {
  id: string; postId: string; userId: string;
  content: string; createdAt: string; votes: number;
};

type PeerReview = {
  id: string; submissionId: string; reviewerId: string;
  criteria: ReviewCriterion[]; feedback: string; score: number;
};

type ReviewCriterion = {

};

type Improvement = {
  id: string; module: string; category: string;

  effort: 'easy' | 'medium' | 'hard'; status: 'pending' | 'done' | 'discarded';

};

type CourseraGap = {
  domain: string; courseraHas: boolean; weHave: boolean;
  parity: number; // 0-100
  actionNeeded?: string;
};
```

- Cada dato de `src/data/` con su fuente y licencia, para que otros reutilicen
