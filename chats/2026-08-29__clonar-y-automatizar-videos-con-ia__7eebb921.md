### 🚨 Diagnóstico Técnico: La Matemática de los 10 Minutos
Las APIs de generación de video de última generación tienen un límite de salida por petición (actualmente entre **5 y 10 segundos** por clip en la mayoría de los modelos comerciales).

#### Módulo 1: El Agente Guionista (LLM + Pydantic)

#### Módulo 2: Motor de Continuidad Visual (El problema del "Flicker")
El mayor reto en videos de IA de larga duración es que la Escena 2 no se parece a la Escena 1. Para resolver esto, el protocolo no usa *Text-to-Video (T2V)* puro, sino un flujo híbrido:
1. La Escena 1 se genera con T2V.
2. El agente extrae el **último fotograma (Last Frame)** de la Escena 1 usando `ffmpeg` o `opencv`.
3. La Escena 2 se envía a la API (ej. Seedance 2.5 o Kling) utilizando la función **Image-to-Video (I2V)** o *Omni-Reference*, inyectando el último fotograma de la escena anterior como semilla visual.

#### Módulo 3: Gestor de Colas Asíncronas (Polling Real)
Las APIs de video no devuelven el MP4 en 3 segundos. Devuelven un `task_id` y el renderizado en la nube toma entre 45 y 120 segundos. Tu agente debe implementar un *Polling* robusto con reintentos (Exponential Backoff).

```python
import httpx
import asyncio

async def poll_video_task(api_url: str, task_id: str, headers: dict):
    """
    Protocolo real de espera para APIs como MiniMax o Seedance.
    Evita bloquear el hilo principal mientras la GPU de la nube renderiza.
    """
    async with httpx.AsyncClient() as client:
        while True:
            response = await client.get(f"{api_url}/status/{task_id}", headers=headers)
            data = response.json()
            
            if data['status'] == 'SUCCESS':
                return data['video_url']
            elif data['status'] in ['FAILED', 'MODERATION_BLOCKED']:
                raise Exception(f"Renderizado falló: {data.get('error_message')}")
            
            # Espera asíncrona de 10 segundos antes de volver a consultar
            await asyncio.sleep(10) 
```

#### Módulo 4: Ensamblaje y Postproducción Avanzada (FFmpeg Complex)
Unir 80 clips con `-c copy` generará cortes secos que arruinan la retención de audiencia en YouTube/TikTok. El agente debe construir un *Complex Filtergraph* en FFmpeg para aplicar **Crossfades (xfade)** automáticos y mezclar la voz en off (TTS) con la música de fondo.

Comando FFmpeg dinámico que tu script de Python debe construir y ejecutar vía `subprocess`:

```bash
  [v01][2:v]xfade=transition=fade:duration=1:offset=14[v02]; \
```

#### Fase B: Postproducción con Transiciones (El Secreto Técnico)
El mayor error al clonar estos repositorios es usar un `concat` simple de FFmpeg. Las IAs de video generan variaciones de iluminación y "ruido" entre clips, por lo que un corte directo se ve como un salto brusco. Tu agente debe usar **Fundidos Cruzados (Crossfade)**.

```python
import ffmpeg

def compile_final_movie(video_files):
    streams = []
    # 1. Normalizar todos los clips a 24fps y 1080p
    for v in video_files:
        streams.append(ffmpeg.input(v).filter('fps', fps=24).filter('scale', 1920, 1080))
    
    # 2. Concatenación con crossfade de 1 segundo para suavizar uniones
    current = streams[0]
    offset = 29 # El fundido inicia en el segundo 29 (duración 30s - 1s de transición)
    
    for i in range(1, len(streams)):
        current = ffmpeg.filter(
            [current, streams[i]], 
            'xfade', 
            transition='fade', 
            duration=1, 
            offset=offset * i
        )
```

### 🚀 Módulo 2: Integración Asíncrona con MiniMax H3 (Con Referencia de Sujeto)
A diferencia de las llamadas síncronas, las APIs de video de alta gama (MiniMax, Kling, Seedance) operan mediante un patrón **Submit → Poll → Download**. Este código implementa el polling asíncrono con reintentos exponenciales y el uso del parámetro `subject_reference` (o `first_frame_url` en la nomenclatura específica de MiniMax) para mantener la identidad del personaje a lo largo de las 20 escenas.

```python
import asyncio
import httpx
import os
from typing import List

# Configuración de la API (Reemplazar con endpoints reales de MiniMax / Fal.ai / Replicate)
MINIMAX_API_URL = "https://api.minimax.chat/v1/video_generation"
API_KEY = os.getenv("MINIMAX_API_KEY")

async def download_video(url: str, filename: str):
    """Descarga asíncrona del video renderizado con manejo de streams para archivos grandes (3-5GB totales)."""
    async with httpx.AsyncClient(timeout=60.0) as client:
        async with client.stream("GET", url) as response:
            response.raise_for_status()
            with open(filename, "wb") as f:
                async for chunk in response.aiter_bytes(chunk_size=8192):
                    f.write(chunk)
    print(f"✅ Descargado: {filename}")

async def poll_task_status(task_id: str, max_retries: int = 60) -> str:
    """Sistema de polling con backoff exponencial para esperar el renderizado en la nube."""
    for attempt in range(max_retries):
        async with httpx.AsyncClient() as client:
            headers = {"Authorization": f"Bearer {API_KEY}"}
            response = await client.get(f"{MINIMAX_API_URL}/query?task_id={task_id}", headers=headers)
            data = response.json()
            
            if data.get("status") == "SUCCESS":
                return data["file"]["video_url"]
            elif data.get("status") in ["FAILED", "REJECTED"]:
                raise RuntimeError(f"Fallo en renderizado: {data.get('reason')}")
            
            # Espera progresiva: 5s, 10s, 15s... para no saturar la API
            await asyncio.sleep(5 + (attempt * 2))
            
    raise TimeoutError("El renderizado excedió el tiempo máximo de espera.")

async def render_scene_minimax(scene_id: int, prompt: str, reference_image_url: Optional[str] = None) -> str:
    print(f"🎬 [Agente] Enviando Escena {scene_id} a cola de renderizado...")
    
    payload = {
        "model": "minimax-h3",
        "prompt": prompt.replace("[REF_IMG] ", ""), # Limpieza para el prompt de texto
        "duration": 10, # MiniMax H3 estándar: 10s por clip
        "aspect_ratio": "16:9"
    }
    
    # Inyección crítica de coherencia visual
    if reference_image_url:
        payload["first_frame_url"] = reference_image_url # Parámetro clave de MiniMax para I2V
        
    async with httpx.AsyncClient() as client:
        headers = {
            "Authorization": f"Bearer {API_KEY}",
            "Content-Type": "application/json"
        }
        response = await client.post(f"{MINIMAX_API_URL}/submit", json=payload, headers=headers)
        task_id = response.json()["task_id"]
        
    # Esperar a que la nube termine el trabajo
    video_url = await poll_task_status(task_id)
    
    # Descargar localmente para el ensamblaje
    filename = f"output/scene_{scene_id:02d}.mp4"
    os.makedirs("output", exist_ok=True)
    await download_video(video_url, filename)
    
    return filename

async def generate_full_movie(scenes: List[dict], first_frame_url: str):
    """Orquestador principal que gestiona el paralelismo controlado."""
    # Usamos Semaphore para limitar a 3 renderizados simultáneos y evitar Rate Limits (429 Too Many Requests)
    semaphore = asyncio.Semaphore(3)
    
    async def bounded_render(scene):
        async with semaphore:
            # La escena 1 usa la imagen maestra. Las siguientes usan el último frame de la escena anterior (lógica a implementar en el pipeline real)
            ref_url = first_frame_url if scene["scene_id"] == 1 else None 
            return await render_scene_minimax(scene["scene_id"], scene["visual_prompt"], ref_url)

    tasks = [bounded_render(scene) for scene in scenes]
    return await asyncio.gather(*tasks)
```

### 🎬 Módulo 3: Compilación FFmpeg con Cálculo de Offset Acumulativo (Corregido)
El código anterior de `offset * i` es un error común. Si el clip 1 dura 30s y el clip 2 dura 30s, el fundido del clip 3 debe empezar en el segundo 58 (30 + 30 - 2 segundos de fundido acumulado), no en el 60. Esta función calcula el `offset` de forma dinámica y precisa.

```python
import ffmpeg
import json

def compile_documentary(video_files: List[str], output_filename: str = "largometraje_final.mp4"):
    print("🔗 [Agente] Iniciando compilación con crossfades dinámicos...")
    
    inputs = []
    filter_complex = []
    current_duration = 0.0
    fade_duration = 1.5 # Duración del fundido en segundos
    
    # 1. Preparar todos los inputs y normalizar a 24fps, 1080p, yuv420p (estándar de cine)
    for i, file in enumerate(video_files):
        inputs.append(ffmpeg.input(file))
        filter_complex.append(
            f"[{i}:v]fps=24,scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,setsar=1[v{i}];"
        )
        filter_complex.append(
            f"[{i}:a]aformat=sample_fmts=fltp:sample_rates=48000:channel_layouts=stereo[a{i}];"
        )

    # 2. Construir la cadena de xfade (video) y acrossfade (audio)
    last_video = "v0"
    last_audio = "a0"
    
    # Obtener duraciones reales de cada clip usando ffprobe (simulado aquí con un valor fijo de 30s para el ejemplo)
    # En producción: duration = float(ffmpeg.probe(file)['format']['duration'])
    clip_durations = [30.0] * len(video_files) 

    for i in range(1, len(video_files)):
        next_video = f"v{i}"
        next_audio = f"a{i}"
        
        # El offset es la duración acumulada anterior MENOS la duración del fundido
        offset = current_duration - fade_duration if current_duration > 0 else 0
        
        out_video = f"v_out{i}"
        out_audio = f"a_out{i}"
        
        # Filtro de video crossfade
        filter_complex.append(
            f"[{last_video}][{next_video}]xfade=transition=fade:duration={fade_duration}:offset={offset}[{out_video}];"
        )
        # Filtro de audio crossfade
        filter_complex.append(
            f"[{last_audio}][{next_audio}]acrossfade=d={fade_duration}:c1=tri:c2=tri[{out_audio}];"
        )
        
        last_video = out_video
        last_audio = out_audio
        current_duration += clip_durations[i]

    # 3. Ensamblar el comando final
    stream = ffmpeg.filter(ffmpeg.concat(*[ffmpeg.input(f) for f in video_files], v=1, a=1), 'format', 'yuv420p')
    
    # Nota: La construcción manual del filter_complex es más robusta para xfade que el concat simple
    # Ejecución real:
    command = (
        ffmpeg.output(
            *[ffmpeg.input(f) for f in video_files], # Inputs
            output_filename,
            **{"c:v": "libx264", "crf": 18, "preset": "slow", "c:a": "aac", "b:a": "192k"}
        )
        .global_args("-filter_complex", "".join(filter_complex))
        .global_args("-map", f"[{last_video}]")
        .global_args("-map", f"[{last_audio}]")
        .overwrite_output()
    )
    
    print("⚙️ Ejecutando FFmpeg (esto puede tomar varios minutos dependiendo de la CPU)...")
    command.run(capture_stdout=True, capture_stderr=True)
    print(f"✅ Video final compilado exitosamente: {output_filename}")
```
