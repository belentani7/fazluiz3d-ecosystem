**Pseudocódigo del algoritmo completo**
```
ENTRADA seed (string|número)
1. h = xmur3(seed)            → estado 32-bit
2. R = mulberry32(h)          → secuencia determinista
3. spec = mapear(R)           → parámetros DENTRO de rangos sellados NOIACORE
4. RENDER = SVG(E04) | GLSL(E05) | CANVAS(E06)   ← todo local
5. CACHE["nc:asset:"+seed] = RENDER
6. seed++ → repetir ∞
```
**Propiedades garantizadas:** determinismo (mismo seed = mismo asset en cualquier máquina), infinitud (espacio de seeds 2³² por posición), cero network/API/keys, paleta imposible de violar, y compatibilidad con SSR/estático (los SVG data-URI se pueden pre-generar en build).
