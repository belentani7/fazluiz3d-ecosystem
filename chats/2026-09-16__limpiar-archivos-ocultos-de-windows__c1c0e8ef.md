## [ASSISTANT] 2026-09-16 13:24 · Qwen3.7-Plus

A continuación, se presenta una guía exhaustiva, técnica y basada en fuentes especializadas para identificar, comprender y eliminar de forma segura los archivos ocultos y el denominado "espacio fantasma" en Windows, optimizando el rendimiento del equipo sin recurrir a software de terceros innecesario o peligroso.

---

### 1. ¿Qué es la "basura indetectable" o "espacio fantasma" en Windows?
Windows acumula con el tiempo archivos temporales, cachés, residuos de actualizaciones y datos de aplicaciones desinstaladas que el sistema no muestra en el análisis de almacenamiento convencional [[3]]. Esto genera una discrepancia entre el espacio real libre y el reportado por el sistema, conocida como "espacio fantasma", que puede llegar a ocupar decenas de gigabytes y ralentizar el equipo al saturar la capacidad de lectura/escritura del disco [[7]]. 

Estos archivos no son literalmente "indetectables", sino que el Explorador de archivos de Windows oculta por defecto las carpetas del sistema protegidas y no calcula su peso en las propiedades básicas de la unidad [[9]].

### 2. Principales acumuladores de espacio oculto y ralentización
- **Archivos temporales (`Temp` y `%temp%`)**: Se generan automáticamente al usar programas, navegar o instalar software. Deberían eliminarse solos, pero a menudo quedan residuos bloqueados o huérfanos que se acumulan indefinidamente [[19]].
- **Carpeta Prefetch**: Almacena datos para acelerar el arranque de aplicaciones. Con el tiempo, acumula accesos a programas que ya no usas, ocupando espacio innecesario y, en casos de corrupción, ralentizando el inicio [[20]].
- **Residuos de actualizaciones de Windows**: La carpeta `SoftwareDistribution` o las copias de seguridad de versiones anteriores (`Windows.old`) pueden pesar fácilmente más de 10 GB tras una actualización importante del sistema [[3]].
- **Archivos de sistema de hibernación y paginación**: `hiberfil.sys` y `pagefile.sys` son archivos ocultos del sistema que reservan un espacio equivalente a una parte de tu memoria RAM (a menudo entre 6 GB y 16 GB) [[10]].
- **Restos de aplicaciones desinstaladas**: Programas o juegos que, tras su desinstalación, dejan carpetas con capturas, configuraciones o datos residuales en `AppData` que pueden sumar decenas de gigabytes sin que el usuario lo note [[10]].

---

### 3. Protocolo de limpieza segura y profunda (Paso a paso)

*⚠️ Advertencia previa*: Antes de realizar cambios manuales en archivos del sistema, se recomienda crear un **Punto de restauración** del sistema para poder revertir cualquier cambio accidental de forma inmediata [[19]].

#### Fase A: Limpieza manual de carpetas temporales y Prefetch
1. Presiona las teclas `Windows + R` para abrir la ventana de Ejecutar.
2. Escribe `%temp%` y pulsa Enter. Selecciona todo el contenido (`Ctrl + E` o `Ctrl + A`) y elimínalo con `Shift + Suprimir` (para evitar que pasen por la Papelera de Reciclaje y se borren de forma permanente) [[20]].
3. Si aparece un aviso de "Archivo en uso", marca la casilla "Hacer esto para todos los elementos actuales" y haz clic en **Omitir**. Nunca fuerces el borrado de archivos que el sistema esté usando activamente en ese momento [[19]].
4. Repite el proceso: `Windows + R`, escribe `temp` (sin los símbolos de porcentaje) y elimina el contenido con los mismos criterios.
5. Finalmente, en la misma ventana de Ejecutar, escribe `prefetch`, acepta los permisos de administrador, selecciona todo y elimina. Windows regenerará aquí únicamente lo necesario para los programas que uses habitualmente [[20]].

#### Fase B: Uso de herramientas nativas de Windows (Método más seguro)
1. **Liberador de espacio en disco**: Búscalo en el Menú de Inicio y selecciona la unidad principal (C:). Haz clic en el botón **"Limpiar archivos de sistema"** (requiere permisos de administrador). Esto permitirá eliminar residuos de actualizaciones de Windows, archivos de registro de actualizaciones y versiones anteriores de Windows, que son los mayores culpables del espacio fantasma [[2]].
2. **Sensor de almacenamiento**: Ve a *Configuración > Sistema > Almacenamiento* y actívalo. Configura la "Limpieza automática de contenido de usuario" para que vacíe periódicamente la Papelera de Reciclaje y la carpeta de Descargas sin intervención manual, previniendo la acumulación futura [[2]].

#### Fase C: Recuperación avanzada de espacio (Opcional pero efectiva)
- **Desactivar la hibernación**: Si no utilizas la función de hibernación (diferente de "Suspender"), puedes eliminar el archivo `hiberfil.sys`. Abre el Símbolo del sistema (CMD) o PowerShell como Administrador y ejecuta: `powercfg -h off`. Esto liberará instantáneamente varios gigabytes (equivalentes a ~40-75% de tu RAM instalada) [[10]].
- **Gestión del archivo de paginación**: Si dispones de 16 GB o más de RAM, puedes configurar el archivo de paginación para que tenga un tamaño máximo limitado en *Configuración avanzada del sistema > Rendimiento > Opciones avanzadas > Memoria virtual*.

---

### 4. Diagnóstico profesional: Cómo hacer visible lo "indetectable"
Si tras estos pasos el espacio del disco sigue sin cuadrar, el Explorador de Windows no es la herramienta adecuada para el diagnóstico. Se recomienda el uso de utilidades gratuitas y portables que leen el sistema de archivos a nivel maestro (MFT), mostrando el peso real de cada carpeta en segundos:

- **WizTree**: Es la opción más rápida y recomendada. Escanea el disco duro y muestra una vista de "árbol" y un mapa de calor visual, permitiendo identificar carpetas ocultas de aplicaciones, restos de juegos o archivos de registro masivos que Windows oculta por defecto [[10]].
- **TreeSize Free**: Alternativa clásica y fiable que ofrece un desglose jerárquico del espacio ocupado, útil para verificar qué carpeta específica dentro de `AppData` o `ProgramData` está consumiendo recursos [[10]].

*Procedimiento seguro*: Ejecuta la herramienta como administrador, identifica las carpetas de mayor peso, verifica su contenido antes de borrar y, en caso de duda, mueve los archivos a otra unidad o a la nube en lugar de eliminarlos directamente [[10]].

---

### 5. Buenas prácticas para evitar la reincidencia
- **Evita "limpiadores de registro" o optimizadores de terceros** de dudosa reputación. A menudo generan más basura, muestran publicidad invasiva o dañan claves del sistema. Las herramientas nativas de Windows combinadas con un visualizador como WizTree son suficientes y 100% seguras [[10]].
- **Verificación post-desinstalación**: Tras desinstalar una aplicación, verifica manualmente en `C:\Archivos de programa` y en `C:\Usuarios\[TuUsuario]\AppData` (Local y Roaming) si quedan carpetas residuales con el nombre del software y elimínalas [[19]].
- **Mantenimiento preventivo**: Mantén activado el Sensor de almacenamiento de Windows para que la limpieza sea un proceso continuo en segundo plano y no requiera intervención manual periódica [[2]].

```powershell
# SCRIPT DE ANÁLISIS COMPLETO DEL DISCO - WINDOWS
# Genera: Mapa de archivos, porcentajes, duplicados y archivos similares
# ============================================================================

param(
    [string]$Ruta = "C:",
    [string]$RutaSalida = "$env:USERPROFILE\Desktop\Analisis_Disco",
    [int]$ProfundidadMaxima = 10,
    [int]$TamanoMinimoMB = 10
)

# Crear carpeta de salida
if (!(Test-Path $RutaSalida)) {
    New-Item -ItemType Directory -Path $RutaSalida -Force | Out-Null
}

Write-Host "============================================" -ForegroundColor Cyan
Write-Host "INICIANDO ANÁLISIS COMPLETO DEL DISCO" -ForegroundColor Cyan
Write-Host "Ruta: $Ruta" -ForegroundColor Yellow
Write-Host "============================================" -ForegroundColor Cyan

# ============================================================================
# 1. OBTENER ESPACIO TOTAL DEL DISCO
# ============================================================================
Write-Host "`n[1/5] Calculando espacio total del disco..." -ForegroundColor Green
$disco = Get-PSDrive -PSProvider FileSystem | Where-Object { $_.Root -eq "$Ruta\" } | Select-Object -First 1
if (!$disco) {
    $discoInfo = Get-Volume | Where-Object { $_.DriveLetter -eq $Ruta.Replace(":", "") }
    $espacioTotal = $discoInfo.Size
    $espacioLibre = $discoInfo.SizeRemaining
} else {
    $espacioTotal = $disco.Used + $disco.Free
    $espacioLibre = $disco.Free
}
$espacioOcupado = $espacioTotal - $espacioLibre

Write-Host "Espacio Total: $([math]::Round($espacioTotal/1GB, 2)) GB" -ForegroundColor White
Write-Host "Espacio Ocupado: $([math]::Round($espacioOcupado/1GB, 2)) GB" -ForegroundColor Red
Write-Host "Espacio Libre: $([math]::Round($espacioLibre/1GB, 2)) GB" -ForegroundColor Green

# ============================================================================
# 2. MAPEO COMPLETO DE CARPETAS CON PORCENTAJES
# ============================================================================
Write-Host "`n[2/5] Generando mapa de carpetas con porcentajes..." -ForegroundColor Green

$hashTablaCarpetas = @{}

# Obtener todas las carpetas y calcular sus tamaños
Get-ChildItem -Path $Ruta -Recurse -Directory -Force -ErrorAction SilentlyContinue | 
Where-Object { $_.FullName.Split('\').Count -le $ProfundidadMaxima } |
ForEach-Object {
    $ruta = $_.FullName
    try {
        $tamano = (Get-ChildItem -Path $ruta -Recurse -File -Force -ErrorAction SilentlyContinue | 
                   Measure-Object -Property Length -Sum).Sum
        if ($tamano -gt 0) {
            $hashTablaCarpetas[$ruta] = $tamano
        }
    } catch {
        # Ignorar errores de permisos
    }
    
    if ($hashTablaCarpetas.Count % 100 -eq 0) {
        Write-Host "  Procesadas $($hashTablaCarpetas.Count) carpetas..." -ForegroundColor DarkGray
    }
}

# Ordenar por tamaño y calcular porcentajes
$carpetasOrdenadas = $hashTablaCarpetas.GetEnumerator() | 
    Sort-Object { $_.Value } -Descending |
    Select-Object -First 100 |
    ForEach-Object {
        $porcentaje = ([math]::Round(($_.Value / $espacioTotal) * 100, 2))
        [PSCustomObject]@{
            Ruta = $_.Key
            TamanoMB = [math]::Round($_.Value / 1MB, 2)
            TamanoGB = [math]::Round($_.Value / 1GB, 4)
            PorcentajeDelDisco = $porcentaje
            Nivel = ($_.Key.Split('\').Count)
        }
    }

# Exportar a CSV
$carpetasOrdenadas | Export-Csv -Path "$RutaSalida\Mapa_Carpetas_Porcentajes.csv" -NoTypeInformation -Encoding UTF8
Write-Host "  ✓ Guardado: Mapa_Carpetas_Porcentajes.csv" -ForegroundColor Green

# ============================================================================
# 3. DETECCIÓN DE ARCHIVOS DUPLICADOS (POR HASH)
# ============================================================================
Write-Host "`n[3/5] Buscando archivos duplicados por hash..." -ForegroundColor Green

$hashArchivos = @{}
$archivosGrandes = Get-ChildItem -Path $Ruta -Recurse -File -Force -ErrorAction SilentlyContinue |
    Where-Object { $_.Length -gt ($TamanoMinimoMB * 1MB) } |
    Group-Object Length |
    Where-Object { $_.Count -gt 1 } |
    Select-Object -ExpandProperty Group

Write-Host "  Analizando $($archivosGrandes.Count) archivos con tamaños duplicados..." -ForegroundColor Yellow

$duplicados = @()
$contador = 0

foreach ($grupo in $archivosGrandes) {
    $contador++
    if ($contador % 500 -eq 0) {
        Write-Host "    Procesados $contador grupos..." -ForegroundColor DarkGray
    }
    
    $hash = Get-FileHash -Path $grupo.FullName -Algorithm MD5 -ErrorAction SilentlyContinue
    if ($hash) {
        if ($hashTablaArchivos.ContainsKey($hash.Hash)) {
            $duplicados += [PSCustomObject]@{
                Hash = $hash.Hash
                TamanoMB = [math]::Round($grupo.Length / 1MB, 2)
                Ruta1 = $hashTablaArchivos[$hash.Hash]
                Ruta2 = $grupo.FullName
                FechaModificacion1 = (Get-Item $hashTablaArchivos[$hash.Hash]).LastWriteTime
                FechaModificacion2 = $grupo.LastWriteTime
            }
        } else {
            $hashTablaArchivos[$hash.Hash] = $grupo.FullName
        }
    }
}

# Agrupar y exportar duplicados
if ($duplicados.Count -gt 0) {
    $duplicadosAgrupados = $duplicados | Group-Object Hash | ForEach-Object {
        $grupo = $_.Group
        [PSCustomObject]@{
            Hash = $grupo[0].Hash
            TamanoMB = $grupo[0].TamanoMB
            CantidadCopias = $grupo.Count
            Ruta1 = $grupo[0].Ruta1
            Fecha1 = $grupo[0].FechaModificacion1
            Ruta2 = $grupo[0].Ruta2
            Fecha2 = $grupo[0].FechaModificacion2
            EspacioDesperdiciadoMB = ($grupo.Count - 1) * $grupo[0].TamanoMB
        }
    }
    
    $duplicadosAgrupados | Export-Csv -Path "$RutaSalida\Archivos_Duplicados.csv" -NoTypeInformation -Encoding UTF8
    Write-Host "  ✓ Guardado: Archivos_Duplicados.csv ($($duplicadosAgrupados.Count) grupos)" -ForegroundColor Green
    
    $espacioDuplicados = ($duplicadosAgrupados | Measure-Object -Property EspacioDesperdiciadoMB -Sum).Sum
    Write-Host "  Espacio desperdiciado en duplicados: $([math]::Round($espacioDuplicados, 2)) MB" -ForegroundColor Yellow
} else {
    Write-Host "  No se encontraron duplicados exactos" -ForegroundColor Cyan
}

# ============================================================================

# ============================================================================

# Agrupar por nombre base (sin extensión)

    if ($grupo.Count -gt 1) {
        # Calcular similitud por tamaño
        $tamanos = $grupo.Group | Select-Object FullName, Length, LastWriteTime
        
        for ($i = 0; $i -lt $tamanos.Count; $i++) {
            for ($j = $i + 1; $j -lt $tamanos.Count; $j++) {
                $tam1 = $tamanos[$i].Length
                $tam2 = $tamanos[$j].Length
                $tamMax = [Math]::Max($tam1, $tam2)
                $tamMin = [Math]::Min($tam1, $tam2)
                
                # Calcular porcentaje de similitud de tamaño
                $similitudTamaño = [math]::Round(($tamMin / $tamMax) * 100, 2)
                
                if ($similitudTamaño -ge 90) {  # Al menos 90% similares en tamaño
                    $similares += [PSCustomObject]@{
                        Archivo1 = $tamanos[$i].FullName
                        Tamano1_MB = [math]::Round($tam1 / 1MB, 2)
                        Fecha1 = $tamanos[$i].LastWriteTime
                        Archivo2 = $tamanos[$j].FullName
                        Tamano2_MB = [math]::Round($tam2 / 1MB, 2)
                        Fecha2 = $tamanos[$j].LastWriteTime
                        Similitud_Tamaño = $similitudTamaño
                        Diferencia_KB = [math]::Round([Math]::Abs($tam1 - $tam2) / 1KB, 2)
                    }
                }
            }
        }
    }
    
    if ($similares.Count % 100 -eq 0 -and $similares.Count -gt 0) {
        Write-Host "    Encontrados $($similares.Count) pares similares..." -ForegroundColor DarkGray
    }
}

if ($similares.Count -gt 0) {
    $similares | Sort-Object Similitud_Tamaño -Descending | 
        Export-Csv -Path "$RutaSalida\Archivos_Similares.csv" -NoTypeInformation -Encoding UTF8
    Write-Host "  ✓ Guardado: Archivos_Similares.csv ($($similares.Count) pares)" -ForegroundColor Green
} else {
    Write-Host "  No se encontraron archivos similares" -ForegroundColor Cyan
}

# ============================================================================
# 5. RESUMEN VISUAL Y ESTADÍSTICAS
# ============================================================================
Write-Host "`n[5/5] Generando resumen..." -ForegroundColor Green

# Top 20 carpetas más pesadas
Write-Host "`n============================================" -ForegroundColor Cyan
Write-Host "TOP 20 CARPETAS MÁS PESADAS" -ForegroundColor Cyan
Write-Host "============================================" -ForegroundColor Cyan

$carpetasOrdenadas | Select-Object -First 20 | Format-Table -AutoSize @{
    Label = "Porcentaje"; Expression = { "$($_.PorcentajeDelDisco)%" }; Alignment = "Right"
}, @{
    Label = "Tamaño GB"; Expression = { $_.TamanoGB }; Alignment = "Right"
}, @{
    Label = "Ruta"; Expression = { $_.Ruta.Substring([Math]::Max(0, $_.Ruta.Length - 60)) }
}

# Resumen final
$resumen = [PSCustomObject]@{
    Espacio_Total_GB = [math]::Round($espacioTotal / 1GB, 2)
    Espacio_Ocupado_GB = [math]::Round($espacioOcupado / 1GB, 2)
    Espacio_Libre_GB = [math]::Round($espacioLibre / 1GB, 2)
    Porcentaje_Ocupado = [math]::Round(($espacioOcupado / $espacioTotal) * 100, 2)
    Total_Carpetas_Analizadas = $hashTablaCarpetas.Count
    Archivos_Duplicados_Encontrados = if ($duplicados.Count -gt 0) { $duplicadosAgrupados.Count } else { 0 }
    Archivos_Similares_Encontrados = $similares.Count
}

$resumen | Export-Csv -Path "$RutaSalida\Resumen_Analisis.csv" -NoTypeInformation -Encoding UTF8

Write-Host "`n============================================" -ForegroundColor Cyan
Write-Host "RESUMEN FINAL" -ForegroundColor Cyan
Write-Host "============================================" -ForegroundColor Cyan
Write-Host "Espacio Total:     $($resumen.Espacio_Total_GB) GB" -ForegroundColor White
Write-Host "Espacio Ocupado:   $($resumen.Espacio_Ocupado_GB) GB ($($resumen.Porcentaje_Ocupado)%)" -ForegroundColor Red
Write-Host "Espacio Libre:     $($resumen.Espacio_Libre_GB) GB" -ForegroundColor Green
Write-Host "Carpetas analizadas: $($resumen.Total_Carpetas_Analizadas)" -ForegroundColor Yellow
Write-Host "Duplicados:        $($resumen.Archivos_Duplicados_Encontrados) grupos" -ForegroundColor Magenta
Write-Host "Archivos similares: $($resumen.Archivos_Similares_Encontrados) pares" -ForegroundColor Magenta
Write-Host "============================================" -ForegroundColor Cyan
Write-Host "Archivos guardados en: $RutaSalida" -ForegroundColor Green
Write-Host "============================================" -ForegroundColor Cyan

# Abrir carpeta de resultados
Write-Host "`nAbriendo carpeta de resultados..." -ForegroundColor Cyan
Invoke-Item $RutaSalida
```

```powershell
# Análisis rápido de C:
$Ruta = "C:"
$Salida = "$env:USERPROFILE\Desktop\Analisis"
New-Item -ItemType Directory -Path $Salida -Force | Out-Null

# Obtener top 50 carpetas
Get-ChildItem $Ruta -Recurse -Directory -Force -ErrorAction SilentlyContinue | 
ForEach-Object {
    $tam = (Get-ChildItem $_.FullName -Recurse -File -Force -ErrorAction SilentlyContinue | 
            Measure-Object -Property Length -Sum).Sum
    if ($tam -gt 0) {
        [PSCustomObject]@{
            Carpeta = $_.FullName
            TamanoGB = [math]::Round($tam/1GB, 2)
        }
    }
} | Sort-Object TamanoGB -Descending | Select-Object -First 50 | 
Export-Csv "$Salida\Top_Carpetas.csv" -NoTypeInformation
```
